01Work

Microsoft Azure Core

Software Engineering Intern · Dublin · Jun 2026 – Sep 2026

Releasing on the Azure Core infrastructure team meant juggling about 15 tabs and bookmarks: approvals in one place, queued pipelines in another, compliance checks somewhere else. I built an end-to-end release orchestration agent that brings all of it into one place, with the safe-shipping logic built in so every required gate is visible and checked before code reaches production.

I also profiled where our CI time was going and added targeted build caching across pipeline tasks. Build runtimes dropped by up to 33%, which adds up to more than 80 hours of developer time saved every week across the team's pipeline runs.

Deloitte Public Sector & Enterprise Solutions

Junior Developer · Dublin · May 2025 – Feb 2026

My team was testing by hand, so I started our test automation. I designed and built a Playwright regression framework that grew to over 400 end-to-end tests across multiple suites. Each one runs in about 3 minutes and replaces 20 to 40 minutes of manual testing and chasing results, which works out at 130+ hours saved on every full regression cycle.

After my placement ended, Deloitte set up a dedicated Test Automation team to take the framework forward. Alongside that I built full-stack features in C#, JavaScript, Blazor and KnockoutJS, and worked with SQL Server, Redis and Azure DevOps.
